SGHSS-> Sistema de Gestão Hospitalar Segura e Sustentável

API REST desenvolvida com Django para gestão, focado em segurança e controle de leitos.

----> Funcionalidades
**Gestão de perfis:** Admin, Médico, Enfermeiro, Secretaria e Paciente.

**Consultas:** Agendamento e emissão de receita digital(apenas médicos).

**Leitos:**Controle de ocupação e controle de leitos com validação de paciente vinculado.

**Relatórios:** Informação em tempo real para administradores.

----> Tecnologias
-Python / Django / Django Rest Framework

-SQLite(Banco de dados)

-JWT(Autenticação)

----> Modelagem
O projeto possui um DER completo e diagrama de classes gerados via 'django-extensions'.
